# Object-Oriented Programming Practices

## 📝 Description
This repository contains a collection of code practices, exercises, and small implementations developed to strengthen understanding of fundamental Object-Oriented Programming (OOP) principles and design patterns.

## 💡 Key Topics Covered
- Encapsulation, Inheritance, Polymorphism, and Abstraction.
- Class design and relationships (Association, Aggregation, Composition).
- SOLID Principles application.
- Basic design patterns implementation.
